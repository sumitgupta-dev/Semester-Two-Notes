1. Evolution of Programming Methodologies

Initially, software development relied on procedural programming (top-down approach, focusing on functions/actions). However, as software grew, procedural languages faced limitations: data was often globally accessible (risking accidental modification), debugging was hard, and the model didn't map well to real-world entities.

To overcome this, Object-Oriented Programming (OOP) was developed. In the 1970s and 1980s, Bjarne Stroustrup integrated OOP concepts into the C language, creating C++ (a superset of C with features like classes and inheritance). OOP focuses on data rather than actions, organizing programs around "objects."

2. Core Concepts of OOP

Objects

Run-time entities that represent real-world items (e.g., a student, a car). They occupy memory, combine data (attributes), and have functions (methods) that operate on that data.

Classes

A blueprint or user-defined data type used to create objects. It defines the structure (data) and behavior (functions) that all instances (objects) of that class will share.

Encapsulation & Data Hiding

Bundling data and functions into a single unit (class). It protects an object's data from unintended external access (data hiding), allowing manipulation only through defined methods.

Data Abstraction

Representing essential features while hiding complex implementation details. It focuses on what an object does rather than how it does it.

Inheritance

Allows a new class (derived class) to acquire properties and behaviors from an existing class (base class). Promotes code reusability and creates class hierarchies.

Polymorphism

Meaning "many forms." Allows a single function or operator to behave differently based on the context (e.g., function overloading, operator overloading).

Dynamic Binding

Also known as late binding. The code to be executed in response to a function call is determined at run-time, providing flexibility.

Message Passing

The process by which objects communicate and interact by sending and receiving messages (invoking methods on each other).

3. Characteristics & Benefits of OOP

OOP follows a bottom-up approach, emphasizes data security, and ties functions closely to data. It partitions work into objects, making it easier to map real-world problems.

Key Benefits:

  • Reusability: Eliminates redundant code via inheritance.
  • Modularity: Builds programs from standard, independent modules.
  • Security: Protects sensitive data through encapsulation.
  • Scalability: Easily extends from small to large systems.
  • Maintainability: Simplifies communication and manages complexity.

4. Difference Between C and C++

Feature C Language C++ Language
Paradigm Procedural Programming (Top-down) Multi-paradigm: Procedural + OOP (Bottom-up)
Focus Steps and procedures Objects and data
I/O Operations printf and scanf cout and cin
Structures Only contain data members Can contain functions and access specifiers
Return in main() Explicit return 0; recommended Compiler automatically adds return 0;

5. Applications of OOP

OOP is widely popular for building large, complex, and maintainable systems. Major applications include:

  • Real-Time Systems: Quick processing of events.
  • Simulation and Modeling: Representing complex systems.
  • Object-Oriented Databases (OODBMS): Managing data as objects.
  • AI and Expert Systems: Simulating human decision-making.
  • Neural Networks & Parallel Programming: Handling complex data structures.
  • CIM/CAM/CAD Systems: Designing and manufacturing industrial processes.

6. Key Terms (Glossary)

OOP (Object-Oriented Programming)
A paradigm using objects to model real-world entities, addressing procedural limitations.
Class
A blueprint defining the data and behavior for objects.
Object
A self-contained entity (instance of a class) containing data and methods.
Encapsulation
Bundling data and methods into a class, restricting outside access.
Abstraction
Hiding implementation details and exposing only essential features.
Inheritance
Deriving a new class from an existing class to reuse code.
Polymorphism
The ability of a function to take multiple forms based on context.
Message Passing
The process of objects communicating by invoking each other's methods.
